# OpenWorkBot — 当前功能

## 定位

产品愿景见 [prd.md](prd.md)。基于 law2 增量开发，不从零重建。
本文描述复制代码的当前行为，不代表已在 OpenWorkBot 运行验收。

## 当前基线

- 单用户本地 Web：React 前端、FastAPI 后端、SQLite、Anthropic 兼容模型接口。
- 三栏界面：会话列表、对话与执行过程、子助手面板。
- 会话新建、历史回放、续聊、删除、重新生成；删除与重跑不撤销文件操作。
- 流式回复、工具参数与结果展示、任务板、子助手输出。
- 文件读写、编辑、枚举、删除及命令执行；Skills 加载。
- 主循环最多 40 个模型步，子助手最多 30 步；工具及子助手串行执行。
- 任务板持久化，但不是调度器；最多 20 项、1 项进行中。
- 上下文压缩与调用日志；历史回放不是跨重启执行恢复。

## 权限与数据

- build 默认变更前确认；edit 自动编辑但删除与一般命令仍需确认；yolo 放宽普通审批，但不绕过硬拒。
- 审批提供仅本次、当前会话指定范围、拒绝三个选项。
- 审批等待与会话授权在内存；重启不恢复。项目规则存 SQLite。
- 文件工具检查工作区路径。PowerShell 仅限定工作目录，不是系统沙箱。
- 同会话只能执行一个 turn；不同会话可以并行。
- 断线后后台继续，页面查询已保存结果；后端重启后未完成轮次显示停止，不自动续跑。
- 对话与工具内容可发送给配置的模型 API；本地模型快照含正文，不得上传版本库。

## 目标能力与当前缺口

愿景包含主动执行、多智能体协同、长期记忆、工作流自动化及反馈迭代。
并行子 Agent、持久调度、跨任务记忆、定时/事件触发、执行恢复尚未实现；设计待逐项确认。
RAG 属于后续 MCP 外部能力，当前不展开其需求；通用 MCP 接入也不作为现有能力宣称。
无登录、多租户与远程服务安全方案，不能直接作为企业部署交付。
